# Scenarios_Climate

Zoning files for climate scenarios, organized by state. Each subfolder contains the zoning data used to power the climate scenario layers in the Peanut Dashboard (US/BR).

## Folders

- `MG` — Minas Gerais zoning files
- `MS` — Mato Grosso do Sul zoning files
- `MT` — Mato Grosso zoning files
- `PR` — Paraná zoning files
- `SP` — São Paulo zoning files

These files support the climate scenario visualizations in the R Shiny application, allowing users to explore projected zoning changes for each state.
