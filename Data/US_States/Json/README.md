# US States — GeoJSON Files

This folder contains GeoJSON county boundary files for the five U.S. states included in the **CercoZon** dashboard.

## Files

- `Alabama_Counties.geojson` — Alabama
- `Florida_Counties.geojson` — Florida
- `Georgia_Couties.geojson` — Georgia
- `North_Carolina_Counties.geojson` — North Carolina
- `Texas_Counties.geojson` — Texas

These files are used to display county boundaries on the interactive maps of the R Shiny application.
