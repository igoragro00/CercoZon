# Data

This directory contains the geospatial data used by the R Shiny dashboard for climate risk zoning of the peanut leaf spot complex in selected peanut-producing states of Brazil and the United States.

## Subfolders

- [`Brazil_States/`](./Brazil_States) — Simplified GeoJSON boundary files for major peanut-producing Brazilian states (Mato Grosso, Mato Grosso do Sul, Minas Gerais, Paraná, and São Paulo).
- [`US_States/`](./US_States) — GeoJSON county boundary files for major peanut-producing U.S. states (Alabama, Florida, Georgia, North Carolina, and Texas).

These files are used to render state- and county-level maps within the dashboard interface.
