# U.S. States

This folder contains the spatial and climate scenario data used by the **CercoZon** dashboard for selected peanut-producing states in the United States.

## Contents

- **`Json/`** – GeoJSON county boundary files used in the interactive maps.
- **`Scenarios_Climate/`** – Climate risk zoning results for current and future climate scenarios.

Detailed information is available in the README file within each folder.
